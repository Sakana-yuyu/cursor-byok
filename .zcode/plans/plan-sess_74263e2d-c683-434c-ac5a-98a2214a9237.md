# 模型配置三屏 UI/产品重构

沿用现有设计系统（Card 渐变边框、Button/Select/Input/Switch/Tooltip 原语、`#10AD5D` 绿主色、`#232323/#292929` 分层背景、`#3f3f3f` 边框、iconify `icon-[mdi--*]`）。不新增依赖、不改数据结构与后端。

## 屏一：供应商列表（ModelConfig.vue）— 紧凑卡片

**顶部工具栏（去冗余）**
- 移除页内重复的大标题「模型配置」（窗口标题栏已有）。改为单行工具栏：
  - 左：统计文字（`8 个供应商 · 134 个模型`；搜索时显示 `筛选出 X/Y`）。
  - 右：搜索框 + 名称/连接分组切换 + 新增模型。
- 保留已实现的搜索/分组逻辑，仅重排视觉。

**紧凑供应商卡**（对应你选的预览）
- 头部：左侧 provider 图标塞进 `size-9` 圆角图标块（bg `#232323`）；右侧品牌 chip（OpenAI/Anthropic）。
- 名称加粗可截断，host 作为下方 `text-xs` muted 文本。
- 统计行合并为一行：`N 个模型`，若已测速追加彩色健康 `· X/Y 可用`（绿；有失败转红）。
- 单独一行 muted 小字 `Key 7995****sdMl`（弱化，不再用大方框）。
- 去掉原来两个占高的「模型数 / API KEY」大方框，卡片高度显著收窄。
- 底部分隔线 + 右对齐操作：删除改为**图标按钮**（`icon-[mdi--trash-can-outline]`，灰→红 hover，`@click.stop`，保留原确认弹窗）+ `进入 →` 绿字。
- 整卡可点进入；grid 改 `minmax(300px,1fr)`，hover 绿边保留。
- 空态/无搜索结果态沿用现有两种提示。

## 屏二：快速添加（ModelEditor.vue，isQuickMode 且非手动）

- 收紧纵向间距（`gap-4`→`gap-3`），字段成组：
  - `模型类型` + `用户分组名称` 放入 2 列 grid。
  - `接口地址（自动补 /v1）` 与 `访问密钥` 一行 2 列。
  - `备注` 整行。
- 「手动添加」提示条重排为更轻的一行（图标 + 说明 + 右侧按钮），降低视觉重量。
- 「拉取模型」主按钮保留；catalog 拉取结果区（含已实现的可用性检测徽标/按钮）视觉与卡片风格对齐。

## 屏三：手动添加 / 编辑（ModelEditor.vue，编辑或手动模式）

- 基础字段区加轻量分组标题「基础信息」，2 列 grid 对齐微调（统一 label + Tooltip 间距）。
- 「协议 / 高级设置」折叠条重做为更克制的一行样式（当前偏重），展开区维持 P3 分区内容。
- 底部「模型测试」区：无结果时给明确的空态（说明 + 引导用顶部「保存并测试」），有结果时展示 ModelAdapterTestCard；去掉当前空卡的突兀感。
- 顶部操作区（取消/保存并测试/保存）对齐与间距微调。
