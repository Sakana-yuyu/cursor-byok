# Cursor-byok Capability Hardening And Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Task 1-13 审查发现的运行时与发布缺陷，加入边界清晰的高星项目机制，并发布包含 macOS DMG 的 `v0.0.71`。

**Architecture:** 保留现有 Forwarder、DelegationScheduler、MCPRuntimeRegistry 和 SkillStore 边界。通过显式 workspace scope、结构化任务快照、无轮询 fan-in、manifest 校验和单一 release manifest 生成器增强现有实现。

**Tech Stack:** Go, Vue 3, Wails 3, GitHub Actions, MCP Go SDK, existing static i18n scanner.

## Global Constraints

- 不修改已安装 Cursor bundle。
- 不引入新的 Agent 框架运行时依赖。
- 不修改已有 protobuf 字段编号。
- 不新增测试文件；复用现有测试和命令级验收。
- 每个任务独立提交，不混入无关改动。
- 保留现有用户未提交浮窗改动，不回滚。
- 最终发布 `v0.0.71`，并包含 macOS ARM64 与 Intel DMG。
