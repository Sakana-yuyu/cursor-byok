> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make History and Logs fill the Settings content height, render sessions as a File Explorer details list, and clarify sparse skill activation.

**Architecture:** Extend the existing Settings flex-height chain only for the History category, then reshape `HistorySettings.vue` without changing its data or mutation APIs. Keep sparse activation behavior untouched and update only its user-facing explanation plus generated translations.

**Tech Stack:** Vue 3, Tailwind CSS utilities, Node test runner, Playwright, Vite static i18n scanner.

## Global Constraints

- Preserve unrelated dirty-worktree changes.
- Keep year/month/day grouping and all existing history actions.
- Do not hard-code the sparse activation Top-K count in UI copy.
- Use Chinese source text and regenerate locale catalogs with the production build.
