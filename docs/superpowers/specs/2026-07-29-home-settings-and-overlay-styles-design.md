# 主页设置收束与三种统计浮窗设计

## 目标

在不重做现有统计展示的前提下，让主页突出运行状态、核心控制和数据概览；将低频配置统一收进标题栏设置入口。同时提供三种可切换、带对应动效的桌面统计浮窗。

## 改动边界

- 保留现有 `HomeMetricsCard` 的结构、缓存命中率样式和交互。
- 保留现有 `StationSpendCard` 站点消耗展示。
- 不新增主页趋势图，不重构指标计算与后端统计接口。
- 不修改已安装的 Cursor 客户端代码或 bundle。
- 不新增测试文件，按仓库现有约束使用构建和浏览器视觉验证。

## 主页信息架构

### 常驻内容

主页顶部使用一个清晰的运行控制区，直接显示：

- 服务运行状态、监听地址和错误状态。
- 本地服务 / 直连 Cursor 模式切换。直连模式不再放在“高级连接”折叠区。
- 请求明细。
- 导出日志。
- 模型配置。
- 服务开启 / 关闭。

运行控制区下方继续显示现有 `HomeMetricsCard`，再显示现有 `StationSpendCard`。

### 从主页移除

以下内容不再作为主页折叠卡展示：

- 高级连接。
- 提示词与本地化。
- 自定义注入。
- 软件使用中文化。

相关能力不删除，只移动到统一设置界面。

## 标题栏设置入口

Windows 标题栏的最小化按钮左侧新增三条杠图标按钮。使用现有图标体系并提供 Tooltip“设置”。点击后打开右侧设置抽屉；抽屉覆盖主内容但不新建原生窗口。

设置抽屉分为以下区块：

### 浮窗

- 显示 / 隐藏统计浮窗。
- 卡片、引擎仪表、球形三种样式切换。
- 始终置顶开关。

### 提示词与本地化

- Codex-X 提示词总开关。
- 软件使用中文化开关。
- 模板、仓库、模式与自定义注入配置入口。
- 拉取最新提示词与查看提示词能力。

复杂配置在抽屉内使用明确分区或二级配置视图，不重新塞回主页。

### 连接与文件

- 高级连接设置。
- 设置文件夹。

请求明细、导出日志和模型配置仍保留在主页，不放入设置抽屉作为唯一入口。

## 浮窗样式

样式选择持久化到本地。打开浮窗时使用上次选择；运行中切换样式时立即更新内容和原生窗口尺寸，不创建重复窗口。

### 卡片式

- 延续当前 2x2 指标布局。
- 透明原生窗口四周保留 6 到 8 像素安全间距，整体面板边框不贴窗口边缘。
- 指标包括缓存命中率、Token 消耗、对话轮次和价值估算。
- 动效：状态点低频呼吸，数值更新时平滑过渡或短暂提亮。

### 引擎仪表式

- 缓存命中率作为主环形仪表。
- Token、对话轮次、价值估算及运行状态排列为紧凑遥测单元。
- 动效：仪表环缓动到新值，低速扫描线或状态光移动。
- 保持深色主题和绿色状态色，不使用大面积渐变装饰。

### 球形式

- 使用透明原生窗口承载圆形主体。
- 球体中心显示缓存命中率，其他指标围绕主体分布。
- 动效：轻微上下悬浮、内层光晕脉冲，指标更新时短暂提亮。
- 窗口使用稳定方形尺寸，避免环绕指标被裁切。

### 动效约束

- 动效不改变布局尺寸，不造成文字位移或遮挡。
- 使用 CSS 动画和过渡，不引入新的动画依赖。
- 遵守 `prefers-reduced-motion: reduce`，减少动画时关闭持续动画，只保留即时状态变化。

## 状态与通信

- 浮窗样式与置顶偏好使用现有前端本地持久化模式保存。
- 原生 `WindowService` 继续维护单例浮窗。
- 新增原生窗口更新方法，用于在样式变化时调整尺寸和置顶状态。
- 浏览器预览 bindings 同步提供无操作 mock，避免预览环境导入失败。
- 设置抽屉直接复用现有提示词、路由模式和窗口服务调用，不复制业务状态。

## 错误处理

- 浮窗创建或设置更新失败时，在主窗口显示现有错误弹窗。
- 浮窗内部指标拉取失败时继续静默保留上次数据，不连续弹窗。
- 提示词保存和刷新继续沿用现有忙碌状态与错误展示。

## 验证

- 生成 Wails bindings 并确认新增窗口方法可导入。
- `go build ./...` 通过。
- 前端生产构建通过。
- 浏览器预览验证主页控制区、设置抽屉和三种浮窗样式。
- 分别按实际原生尺寸截图，确认卡片边框留白、仪表完整、球形指标不裁切。
- 构建新的 Windows 测试包并提供 SHA-256。
