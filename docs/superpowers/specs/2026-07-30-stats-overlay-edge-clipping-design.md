# 统计浮窗贴边裁切修复设计

## 问题

统计浮窗贴左或右边时，前端会切换为竖向胶囊。胶囊包含图标、轮换数据、状态点和贴边时显示的锁定按钮，但后端将收缩窗口高度固定为 `60px`，窗口高度不足会裁切底部内容。

## 方案

保留现有 CSS 贴边变换和窗口定位逻辑，只调整原生窗口的收缩尺寸常量，使竖向胶囊有足够高度，同时给横向胶囊保留现有尺寸。尺寸继续由后端统一计算，前端无需改变交互或坐标保存逻辑。

## 验证

- 运行 `gofmt`。
- 运行 `go build ./...`。
- 运行前端 production build。
- 静态核对四个贴边方向的窗口尺寸与 CSS 胶囊布局，确认没有新增测试文件。

## 范围

- 不修改统计数据来源、刷新周期、贴边阈值、拖拽行为或视觉样式。
- 不修改已安装的客户端，不生成或提交构建产物。
