# 设置页收缩导航与全尺寸布局优化设计

## 状态

- 日期：2026-08-09
- 决策：采用弹性工作区 + 图标窄栏
- 范围：优化 `Settings.vue` 与 `SettingsSidebar.vue` 的布局和收缩态视觉，不改变设置数据、保存流程和路由行为

## 目标

1. 收缩后保留稳定、可识别的图标窄栏。
2. 通过统一选中态、工具提示和“更多”菜单降低收缩态的视觉噪声。
3. 让页头、导航和内容区域处于同一弹性布局上下文。
4. 宽屏充分利用可用空间，中等窗口保持可读控件宽度，窄窗口不产生横向溢出。
5. 保留现有分类、持久化收缩状态、键盘可访问性和减少动效支持。

## 方案

### 导航

- 展开态继续显示分组标题和分类说明。
- 收缩态仅显示统一尺寸的图标按钮，不显示分组标题图标。
- 当前分类使用低饱和背景、左侧绿色强调条和高对比图标。
- 普通分类使用稳定的 hover/focus 样式；每个图标按钮提供 `title` 和可访问名称。
- “更多设置”使用点击打开的右侧对齐菜单，菜单不会因为短暂离开触发区域而消失；选择分类后关闭。
- 窄窗口使用顶部分类选择器，图标窄栏不参与布局。

### 页面布局

- 外层改为 `minmax(0, 1fr)` 弹性工作区，不再让整个页面受 `max-w-[1080px]` 与内容 `max-w-[820px]` 双重限制。
- 导航宽度在展开/收缩两种状态下固定，内容区占据剩余空间并允许滚动。
- 页头和内容共享同一内容列；宽屏内容列扩展，但普通设置行保留合理的最大阅读宽度。
- 内容区域按实际可用宽度自适应：空间不足时单列，空间充足且分类允许时使用双列。
- `sm` 以下切换为纵向布局；分类选择器位于页头下方，内容区域完整占用宽度。
- 所有滚动容器设置 `min-width: 0`、`overflow-x: hidden`，避免长文本和控件撑破窗口。

## 非目标

- 不修改设置分类、数据结构、autosave、路由和持久化键。
- 不修改安装中的 Cursor 客户端或 bundle。
- 不改变其他页面及浮窗运行时样式。

## 验收标准

- 收缩侧栏无红色/突兀外框，图标间距、选中态和 hover 状态统一。
- 收缩态每个可用分类可通过工具提示或“更多”菜单访问。
- 1024px 左右窗口中，页头和设置内容不出现明显空白或挤压。
- 最大化窗口中内容区域能够扩展，设置控件仍保持可读长度。
- 窄窗口无横向滚动；导航、页头和分类内容可正常操作。
- 现有保存状态、分类切换、返回、键盘 focus 和 reduced-motion 行为保持有效。
