# Cursor 3.22.12 兼容适配设计

日期：2026-10-16（Asia/Shanghai）。状态：用户已确认按此范围直接适配。

## 目标与证据

本轮核对上游更新并适配本机实际安装的 Cursor。保留当前 Go/Wails/Vue 架构及既有未提交 External API 改动。

- 本地 HEAD：`9bf446a0`（v1.0.12）。
- 本轮执行 `git fetch upstream --prune`，上游由 `9a8fde27` 更新到 `31e9f5cbc98a7d28cffcb5efbb9323cd3e143354`；区间内 12 个提交仅修改 README.md / README-CN.md，净增 4 行，没有新增功能代码。
- 当前 Cursor 安装包版本：3.22.12；commit：`3a92974361033b2051526321308c2740fe5912c0`。
- 能力扫描命令成功，固定协议与浏览器标记仍存在；静态标记不能证明真实会话成功。
- 对当前 `cursor-always-local/dist/main.js` 执行严格协议提取失败。已确认提取器写死 webpack 参数 `n` / `t`，当前包使用 `r` / `e`；另有大量消息切换到 `static $p()` 包名前缀和 `static $()` 紧凑描述，旧提取器无法读取。

## 方案选择

采用兼容现有提取器并核对协议的方式。直接合并上游会替换当前架构，且上游本轮没有功能变更；手工补写少数生成类型无法形成可重复的同步流程。因此先修复生成链路，再决定实际需要更新的协议面。

## 数据流与实现边界

1. 只读解析安装包，禁止加载执行 bundle、修改 Cursor 文件、设置、凭据或进程。
2. `proto/ext_tool` 从每个 webpack 模块头识别实际 require / exports 参数；导入、ESM 导出、CommonJS 导出和转导出必须保留所属模块边界，不能猜测其他模块的同名符号。
3. 保留既有 protobuf 描述格式，同时静态支持紧凑描述：包名前缀、消息与嵌套消息、标量、引用、可选、重复、map、oneof 和枚举。未知格式、缺失引用、类型冲突必须导致严格模式失败，不能用 bytes / 空类型掩盖。
4. 先生成到忽略目录 `.analysis-tmp/`，连续两次提取结果必须一致并通过 proto 语法解析。比较后只更新确实影响当前协议的源文件；通过既有 `apply_tool` 与 protoc 生成编译输入和 Go 类型，禁止只修改生成文件。
5. 若新版增加当前本地模式实际使用的字段，在现有处理路径中补齐并加针对性验证。仅属于远程机器、云服务或私有推理的新服务不能据此宣称已支持。
6. 既有 `.cursor-app-formatted/` 是 9 月旧快照，本轮依据当前安装包只读解析，不把旧快照作为新版证据。

## 已确认的兼容保留与行为适配

- 新安装包不再包含本地历史导入/投影仍引用的若干旧会话结构，也不再包含旧 `ModelDetails` 上下文字段。原始抽取产物保持与安装包一致，`apply_tool` 通过显式嵌入的兼容片段生成所需旧类型，并严格拒绝字段号复用。保留的旧类型只服务本仓库已有路径，不代表新增官方能力。
- MCP 结果保留 `needs_auth` 提示与 server 的 `error_message`；模型能知道需要认证或具体连接失败，不把无工具误解为正常空目录。
- Canvas 支持旧项目路径、新 agent store 路径和原生 workfile 路径；回灌保存状态，明确区分异步受理、未保存与未知状态，保持原有 TS 诊断输出。
- 新增 Adopt、跨代理、PR 导览和独立 Canvas 工具的协议类型应纳入能力清单，只有实际实现 sender/handler 并有行为测试时才能标记支持。

## 验收

- 新旧 webpack 参数名、CommonJS / ESM 及紧凑描述均有失败后修复的回归测试。
- 缺失和歧义引用仍被拒绝；可选、重复、map、oneof 和枚举的 proto 类型正确。
- 当前 Cursor bundle 严格提取成功，两次输出哈希一致，生成文件语法解析通过。
- 相关 Go 包测试、构建及必要的协议路由验证通过；如涉及前端再执行前端验证。
- 同步记录写明上游真实变更、已适配项、未支持项和测试边界；真实 Cursor 会话及真实供应商调用需要单独证据。

## 风险与回滚

本轮主要风险是紧凑描述误解析导致协议类型错误，以严格校验、结构回归、模块隔离和真实 bundle 提取作为门禁。只读安装包不产生客户端回滚需求。代码回滚仅撤销本轮提取器、协议源及生成链路变更；不得覆盖既有未提交文件，也不执行远端推送或发布。
