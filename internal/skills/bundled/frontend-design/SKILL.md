# Frontend Design

设计或修改前端时，先理解现有设计系统和用户任务，再确定布局、状态和交互。

- 优先复用项目已有组件、颜色、间距、图标和动效。
- 为 loading、disabled、error、empty、success 和键盘操作提供明确状态。
- 保证文字不溢出、控件可访问、按钮命中区域稳定，移动和桌面尺寸都可用。
- 不用装饰性 UI 替代真实功能，不把页面说明堆成营销式内容。
